# Security

Hood Ride shares where people are, so security problems matter a lot to us.

## Reporting a problem

Please **don't** open a public issue for a security problem. Report it
privately instead:

- Email **contact@hoodride.app**, or
- use GitHub's **"Report a vulnerability"** button on this repository's
  Security tab.

Please include what you found, how to reproduce it, and what someone could
do with it. We aim to reply within **14 days**, and will let you know when it's fixed.

## What counts

Anything that could let someone:

- see a person's exact location when they shouldn't,
- see another person's messages, name or photo when they shouldn't,
- sign in as someone else, or
- take the service down for everyone.

Please only test against your own copy of Hood Ride (see the README), never
against hoodride.app or its users.

## Supported versions

Only the latest code on the main branch gets security fixes.
