Hood Ride کون استعمال کر سکتا ہے

Hood Ride استعمال کرنے کا مطلب ہماری شرائطِ استعمال سے اتفاق کرنا بھی ہے۔ آپ کی عمر 18 سال یا اس سے زیادہ ہونی چاہیے۔ Hood Ride اس سے کم عمر کسی کے لیے نہیں ہے، اور ہم جان بوجھ کر 18 سال سے کم عمر کسی شخص سے معلومات جمع نہیں کرتے۔ اگر ہمیں پتہ چلے کہ کوئی اکاؤنٹ 18 سال سے کم عمر کسی شخص کا ہے تو ہم اسے حذف کر دیتے ہیں۔

ہم کیا جمع کرتے ہیں، اور کیوں

جب آپ Google کے ساتھ سائن ان کرتے ہیں تو ہم صرف یہ وصول کرتے اور رکھتے ہیں:

  • Google کی طرف سے ایک اکاؤنٹ نمبر، تاکہ اگلی بار ہمیں معلوم ہو کہ یہ آپ ہی ہیں؛
  • آپ کا پہلا نام: ہم آپ کا پورا نام نہیں رکھتے؛
  • آپ کی پروفائل تصویر کی ایک چھوٹی کاپی، اگر آپ کی کوئی تصویر ہو: یہ سائن ان کرتے وقت بنائی جاتی ہے، ہر بار سائن ان کرنے پر تازہ کی جاتی ہے، اور آپ کے اکاؤنٹ کے ساتھ حذف کر دی جاتی ہے۔

ہم آپ کا ای میل پتہ، آپ کے رابطے، یا آپ کے Google اکاؤنٹ سے کوئی اور چیز نہیں مانگتے اور نہ رکھتے ہیں۔ آپ کا نام اور تصویر صرف اسی اکاؤنٹ سے آتے ہیں؛ انہیں تبدیل کرنے کے لیے انہیں Google پر تبدیل کریں، اور اگلی بار سائن ان کرنے پر، یا جب آپ Google سے ریفریش کریں پر تھپتھپائیں (اوپر دائیں جانب اپنی پروفائل تصویر پر تھپتھپائیں، پھر تبدیل کریں)، تو یہ یہاں بھی تازہ ہو جائیں گے۔

جب آپ ایپ استعمال کرتے ہیں:

  • آپ کا تقریبی علاقہ: جب آپ ڈرائیو کرنے کے لیے دستیاب ہوں یا سواری مانگ رہے ہوں، تو نقشہ آپ کو تقریباً 350 میٹر (تقریباً چوتھائی میل) چوڑے علاقے میں دکھاتا ہے، کبھی آپ کی بالکل درست جگہ نہیں۔ ہم اسے آپ کو قریبی لوگوں کو دکھانے کے لیے استعمال کرتے ہیں۔
  • سواری کے دوران آپ کا درست مقام: صرف آپ کے ہم سفر کے ساتھ، اور صرف جب تک سواری جاری رہے، شیئر کیا جاتا ہے، تاکہ آپ ایک دوسرے کو ڈھونڈ سکیں۔
  • وہ پیغامات جو آپ دوسرے لوگوں کو بھیجتے ہیں، اور سواری کی درخواستیں۔
  • آپ کا IP پتہ، مختصر وقت کے لیے، غلط استعمال روکنے کے لیے (مثلاً کوئی شخص سروس پر بے تحاشا درخواستوں کی بوچھاڑ کر رہا ہو)۔
  • تکنیکی خرابیوں کے لاگز: خرابیوں اور انتباہات کا ریکارڈ، مسائل حل کرنے کے لیے۔ ان میں آپ کا نام، آپ کا مقام یا آپ کے پیغامات نہیں ہوتے؛ کسی خرابی میں کسی اکاؤنٹ نمبر کا ذکر ہو سکتا ہے۔

آپ کے آلے پر: سائن ان کی ایک کوکی آپ کو سائن ان رکھتی ہے (30 دن تک)، اور ایپ یاد رکھتی ہے کہ آپ نے آخری بار نقشے کا کون سا علاقہ استعمال کیا تھا، تاکہ نقشہ وہیں کھلے جہاں آپ تھے، اور یہ کہ آپ نے کون سے پیغامات پڑھ لیے ہیں، تاکہ نئے پیغامات غیر پڑھے دکھائی دیں (صرف یہ کہ کون سے، خود پیغامات کبھی نہیں)۔ سائن آؤٹ کرنے سے یہ ہٹ جاتے ہیں۔ اگر آپ کوئی زبان منتخب کرتے ہیں تو ایک کوکی آپ کا انتخاب ایک سال تک یاد رکھتی ہے (سائن آؤٹ کرنے پر یہ برقرار رہتی ہے، تاکہ سائن ان کا صفحہ آپ کی زبان میں رہے)؛ اگر آپ منتخب نہیں کرتے تو ایپ آپ کے فون کی زبان استعمال کرتی ہے اور کچھ محفوظ نہیں کرتی۔ ایپ کے کام کرنے کے لیے یہ سب ضروری ہیں؛ ہم اشتہاری یا ٹریکنگ کوکیز استعمال نہیں کرتے۔

کون کیا دیکھتا ہے

کونوہ کیا دیکھ سکتے ہیں
قریبی لوگجب وہ آپ پر تھپتھپائیں تو آپ کا پہلا نام اور تصویر، اور آپ کا تقریبی علاقہ (نقشے پر ایک گاڑی یا اٹھے ہوئے ہاتھ کی صورت میں)۔
وہ لوگ جنہیں آپ پیغام بھیجتے ہیںآپ کے پیغامات، پہلا نام اور تصویر۔
مسافر، جب آپ ڈرائیو کر رہے ہوں (وہ جو آپ کی گاڑی پر تھپتھپائیں، آپ سے سواری مانگیں، یا آپ کے ساتھ سفر کریں)آپ کی گاڑی کا رنگ، کمپنی اور ماڈل، جیسا کہ آپ نے ایپ میں درج کیا ہے، تاکہ وہ آپ کو ڈھونڈ سکیں۔ آپ کی نمبر پلیٹ کبھی نہیں (Hood Ride اسے مانگتا ہی نہیں)۔ دوسرے ڈرائیور اسے نہیں دیکھتے۔
وہ لوگ جنہیں آپ پیغام بھیجتے ہیں یا جن سے سواری مانگتے ہیں، جب آپ ڈرائیو نہیں کر رہے ہوتےآپ تقریباً کہاں ہیں (تقریباً 350 میٹر، یعنی تقریباً چوتھائی میل، چوڑا علاقہ، کبھی آپ کی بالکل درست جگہ نہیں)، آپ کے آخری پیغام یا درخواست کے وقت کے مطابق، تاکہ وہ دیکھ سکیں کہ آپ کتنی دور ہیں۔ یہ صرف اس کے ساتھ بھیجا جاتا ہے جو آپ بھیجتے ہیں، اور بات چیت یا درخواست ختم ہونے پر ختم ہو جاتا ہے۔
آپ کا ہم سفرآپ کا درست مقام، صرف سواری کے دوران۔
Hood Rideجو کچھ اس صفحے پر بیان کیا گیا ہے، صرف سروس چلانے کے لیے استعمال ہوتا ہے۔

وہ سروسز جن پر ہم انحصار کرتے ہیں

  • Cloudflare Hood Ride تک آنے والی تمام ٹریفک پہنچاتا ہے اور اسے حملوں سے بچاتا ہے؛ یہ محفوظ کنکشن سنبھالتا ہے، اس لیے اس سے گزرنے والی ٹریفک دیکھ سکتا ہے۔ یہ ہمارے لیے وزٹس کی گنتی بھی کرتا ہے (Cloudflare Web Analytics): کون سے صفحات کھولے جاتے ہیں، کس قسم کا آلہ اور براؤزر، کس سائٹ نے یہاں کا لنک دیا، اور صفحات کتنی تیزی سے لوڈ ہوتے ہیں۔ یہ کوئی کوکی استعمال نہیں کرتا، دوسری سائٹس پر آپ کا پیچھا نہیں کرتا، اور ہم صرف مجموعی تعداد دیکھتے ہیں۔
  • Google سائن ان کی سہولت فراہم کرتا ہے۔ جب آپ سائن ان کرتے ہیں تو Hood Ride آپ کی پروفائل تصویر کی اپنی کاپی بناتا ہے؛ پھر تصاویر Hood Ride کے اپنے سرور سے دکھائی جاتی ہیں، اس لیے Google یہ نہیں دیکھتا کہ کون کس کی تصویر دیکھتا ہے۔ اگر آپ سواری کے دوران نیویگیٹ کریں پر تھپتھپائیں تو Google Maps آپ کی منزل کے ساتھ کھلتا ہے۔
  • OpenFreeMap نقشے کی تصاویر فراہم کرتا ہے۔ آپ کا آلہ انہیں براہ راست مانگتا ہے، اس لیے OpenFreeMap دیکھتا ہے کہ آپ نقشے کا کون سا علاقہ دیکھ رہے ہیں؛ اس کی پالیسی کہتی ہے کہ وہ بطورِ طے شدہ IP پتے لاگ نہیں کرتا۔

ہر ایک کی اپنی رازداری کی پالیسی ہے۔ ہم آپ کی معلومات اشتہارات کے لیے فروخت نہیں کرتے، کرائے پر نہیں دیتے اور نہ ہی شیئر کرتے ہیں، اور ہم کسی اور کو Hood Ride پر آپ کو ٹریک کرنے نہیں دیتے۔

آپ کسی بھی وقت اپنا اکاؤنٹ حذف کر سکتے ہیں: اوپر دائیں جانب اپنی پروفائل تصویر پر تھپتھپائیں، پھر اکاؤنٹ حذف کریں۔ (اگر آپ کسی سواری میں ہیں یا کسی کا انتظار کر رہے ہیں تو پہلے اسے ختم یا منسوخ کریں۔) حذف کرنا فوری اور مستقل ہے: آپ کا اکاؤنٹ ہٹا دیا جاتا ہے، آپ کو نقشے سے ہٹا دیا جاتا ہے، آپ کی بات چیت بند کر دی جاتی ہے، اور آپ ہر آلے سے سائن آؤٹ ہو جاتے ہیں۔ اگر آپ بعد میں دوبارہ سائن ان کریں تو آپ کا نیا اکاؤنٹ شروع ہوگا۔

  • سائن آؤٹ کریں آپ کو آپ کے تمام آلات سے سائن آؤٹ کر دیتا ہے اور آپ کو نقشے سے ہٹا دیتا ہے۔ (اگر آپ کسی سواری میں ہیں یا کسی کا انتظار کر رہے ہیں تو پہلے اسے ختم یا منسوخ کریں۔)
  • آپ خود طے کرتے ہیں کہ آپ کب نظر آئیں: آپ نقشے پر صرف اسی وقت دکھائی دیتے ہیں جب آپ ڈرائیو کرنے کے لیے دستیاب ہوں یا سواری مانگ رہے ہوں۔
  • آپ کے براؤزر یا فون کی ترتیبات مقام تک رسائی کو کنٹرول کرتی ہیں؛ Hood Ride صرف تب پوچھتا ہے جب اسے اس کی ضرورت ہو۔

ہم آپ کی معلومات کیوں استعمال کرتے ہیں (قانونی بنیادیں):

  • وہ سروس فراہم کرنے کے لیے جس کے لیے آپ نے سائن اپ کیا (ایک معاہدہ): آپ کا اکاؤنٹ، نقشے پر آپ کا علاقہ، سواریاں، سواری کی درخواستیں، پیغامات، اور سواری کے دوران آپ کا درست مقام۔
  • ہمارے جائز مفادات: سروس کو محفوظ اور فعال رکھنا (غلط استعمال روکنے کے لیے مختصر وقت کے لیے IP پتے؛ خرابیوں کے لاگز؛ سائن آؤٹ کے ریکارڈ)، اس بات کا ریکارڈ رکھنا کہ آپ نے شرائطِ استعمال سے اتفاق کیا، اور کوکیز کے بغیر وزٹس کی گنتی کرنا (Cloudflare Web Analytics)۔

آپ کے حقوق: آپ اپنی معلومات کی ایک کاپی مانگ سکتے ہیں، ہم سے کہہ سکتے ہیں کہ ہم اسے درست کریں، حذف کریں، یا اس کے استعمال کو محدود کریں، ہمارے اس کے استعمال پر اعتراض کر سکتے ہیں، اور اسے ایک قابلِ منتقلی شکل میں حاصل کر سکتے ہیں۔ کسی بھی وقت اپنا اکاؤنٹ حذف کریں (اوپر دائیں جانب اپنی پروفائل تصویر، پھر اکاؤنٹ حذف کریں)، یا کسی اور چیز کے لیے ہمیں ای میل کریں؛ ہم ایک مہینے کے اندر جواب دیں گے۔ آپ اپنی مقامی ڈیٹا پروٹیکشن اتھارٹی کے پاس شکایت بھی درج کرا سکتے ہیں۔
