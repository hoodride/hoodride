隐私政策

自2026年11月5日起生效

Hood Ride 是一款邻里拼车应用：邻居顺路载邻居。本页用通俗的语言说明 Hood Ride 收集哪些信息、谁能看到、保留多久，以及如何删除你的账号。Hood Ride 在美国运营。如有疑问，请联系：contact@hoodride.app。

简而言之：我们尽可能少地收集信息。我们不出售你的信息，不展示广告，也不在其他网站上追踪你。我们使用 Cloudflare Web Analytics 统计访问量，它不使用 Cookie，也不会在其他网站上跟踪你。你的精确位置只会分享给你的同行伙伴，而且只在行程中分享。

谁可以使用 Hood Ride

使用 Hood Ride 即表示你同时同意我们的使用条款。你必须年满18岁。Hood Ride 不面向未满18岁的人，我们也不会在知情的情况下收集未满18岁者的信息。如果我们得知某个账号属于未满18岁的人，我们会将其删除。

我们收集什么，以及为什么

当你使用 Google 登录时，我们只接收并保留：

  • 来自 Google 的账号编号，以便下次识别出是你；
  • 你的名字（不含姓氏）——我们不保留你的全名；
  • 你的头像的小尺寸副本（如果你有头像）——在你登录时生成，每次登录时更新，并随你的账号一起删除。

我们不会索取或保留你的电子邮件地址、联系人或你 Google 账号中的任何其他内容。你的名字和头像只来自该账号；如需更改，请在 Google 上更改，下次你登录时，或当你点按从 Google 刷新时（点按左上角的头像，然后点按更改），这里会随之更新。

在你使用应用期间：

  • 你的大致区域——当你可以开车载人或正在请求搭车时，地图会把你显示在一个直径约350米（约四分之一英里）的区域内，绝不显示你的确切位置。我们用它向附近的人显示你。
  • 你在行程中的精确位置——只分享给你的同行伙伴，只在行程持续期间分享，以便你们找到彼此。
  • 你发给其他人的消息，以及搭车请求。
  • 你的 IP 地址，短暂保留，用于防止滥用（例如有人向服务发送海量请求）。
  • 技术错误日志——错误和警告的记录，用于修复问题。其中不包含你的名字、位置或消息；某条错误记录可能会提到某个账号编号。

在你的设备上：一个登录 Cookie 让你保持登录状态（直到你退出登录，或你最后一次使用应用后的30天；最长一年）；应用还会记住你上次使用的地图区域，以便地图在你上次所在的位置打开，并记住你已读过哪些消息，以便新消息显示为未读（只记录是哪些消息，绝不保存消息本身）。退出登录会清除这些内容。如果你选择了语言，一个 Cookie 会记住你的选择一年（退出登录后仍会保留，以便登录页面继续使用你的语言）；如果你没有选择，应用会跟随你手机的语言，不存储任何内容。这些都是应用正常运行所必需的；我们不使用广告或追踪 Cookie。

我们依赖的服务

  • Cloudflare 承载所有发往 Hood Ride 的流量并保护其免受攻击；它负责处理安全连接，因此能看到经过它的流量。它还为我们统计访问量（Cloudflare Web Analytics）：打开了哪些页面、使用的是哪类设备和浏览器、从哪个网站链接过来，以及页面加载速度。它不使用 Cookie，不会在其他网站上跟踪你，我们也只能看到汇总数据。
  • Google 提供登录服务。你登录时，Hood Ride 会为你的头像制作自己的副本；之后头像从 Hood Ride 自己的服务器上显示，因此 Google 看不到谁在看谁的头像。如果你在行程中点按导航，Google Maps 会打开并显示你的目的地。
  • OpenFreeMap 提供地图图像。你的设备直接向它请求这些图像，因此 OpenFreeMap 能看到你正在查看地图的哪个区域；其政策称，默认情况下不记录 IP 地址。

上述每项服务都有各自的隐私政策。我们不会为广告目的出售、出租或分享你的信息，也不允许任何其他人在 Hood Ride 上追踪你。

删除账号

你可以随时删除你的账号：点按左上角的头像，然后点按删除账号。（如果你正在行程中或正在等待行程，请先结束或取消。）删除立即生效且无法恢复：你的账号会被移除，你会从地图上消失，你的对话会被关闭，你会在所有设备上退出登录。如果你以后再次登录，将会开始一个新账号。

如果你无法登录，请发送电子邮件至 contact@hoodride.app，我们会帮助你。

你的其他选择

  • 退出登录会让你在所有设备上退出登录，并把你从地图上移除。（如果你正在行程中或正在等待行程，请先结束或取消。）
  • 你可以选择何时可见：只有在你可以开车载人或正在请求搭车时，你才会出现在地图上。
  • 你的浏览器或手机设置控制位置访问权限；Hood Ride 只在需要时才会请求。

请勿跟踪 (Do Not Track)

有些浏览器会发送“Do Not Track”（请勿追踪）信号。Hood Ride 不会跨网站追踪你，也不允许第三方在 Hood Ride 上追踪你，因此该信号在这里不会改变任何事情——我们本来就按照它的要求行事。

安全

所有连接均经过加密（HTTPS）。我们尽可能少地保留信息，应用使用的大部分内容只存在于服务器内存中，并在你下线后不久消失。

本政策的变更

如果我们变更本政策，我们会更新本页面及其生效日期。
